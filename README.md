# Charmies by Sousou

Interface e-commerce de démonstration (Next.js, App Router). Aucune commande, aucun paiement et aucun compte ne sont enregistrés sur un serveur.

## Lancer

```bash
npm install
npm run dev
```

La boutique est servie sur http://localhost:3000. L’administration est sur http://localhost:3000/admin.

Cette étape n’utilise pas de base de données. Ne placez pas d’identifiants dans le code du navigateur.
